Interactive Portfolio Hub: Pure Front-End Web Development Showcase

🔗 Live Hosted Project Link [https://johnolaojo4.github.io/Interactive-Portfolio-Hub/]

📝 Project Overview
This project is a professional personal portfolio hub developed as a capstone showcase of front-end mastery. It serves as a central gateway to three distinct interactive systems: a Recreational Suite, a Calculator System, and an Interactive Game System. The entire project is built using only vanilla web technologies to demonstrate core proficiency in DOM manipulation, responsive design, and state management.

🚀 Key Features
Modern Portfolio Landing Page: A responsive hero section, biography, and project grid with interactive hover effects.

Recreational Suite: Includes a Movie Manager and To-Do List with localStorage persistence and search/filter logic.

Calculator System: A specialized hub featuring a Scientific Calculator, BMI Calculator, and Age Calculator with real-time feedback.

Memory Match Game: An interactive card-flipping game featuring 3D CSS transforms, difficulty scaling, and high-score persistence.

🛠️ Technologies Used
HTML5: Semantic structure for accessibility and SEO.

CSS3: Flexbox/Grid layouts, custom animations, and responsive media queries.

Vanilla JavaScript: DOM manipulation, event listeners, and local storage integration.
